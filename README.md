# DigiNode-Tools/.github

Default community files for every repository in [DigiNode-Tools](https://github.com/DigiNode-Tools).

- `FUNDING.yml` adds the **Sponsor** button to every repository that doesn't have its own. It links to [GitHub Sponsors](https://github.com/sponsors/DigiNode-Tools) and the [DigiNode Tools sponsors page](https://diginode.tools/sponsors/).
